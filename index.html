Как получить личный токен (5 минут)
  1. Открой api.slack.com/apps → Create New App → From scratch, имя любое (например «Shift Hub — Хаям»), выбери ваш рабочий Slack.
  2. Слева OAuth & Permissions → блок User Token Scopes → Add an OAuth Scope → chat:write.
  3. Вверху Install to Workspace → Allow (если нужен админ — Slack попросит его одобрить).
  4. Скопируй User OAuth Token (начинается с xoxp-) и вставь сюда.
Токен хранится только в этом браузере и не попадает в базу сайта. Никому его не показывай.

🔑 Подключи бесплатный Gemini
Нужно один раз — потом ассистент заработает у всей команды.
  1. Открой aistudio.google.com/apikey и войди через Google.
